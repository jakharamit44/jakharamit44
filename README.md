### Engineering Focus

I architect and maintain full-stack web applications, high-volume relational databases, and automated cloud infrastructure. My work centers on clean system design, query optimization, and low-latency deployments.

- **Backend & Systems:** Building production REST APIs, microservices, and serverless edge applications using `.NET / C#`, `Node.js`, `Python`, and `Go`.
- **Database Engineering:** Designing complex schemas, stored procedures, and high-throughput reporting pipelines across `SQL Server`, `PostgreSQL`, and `Redis`.
- **Cloud & Infrastructure:** Deploying containerized workloads and reverse-proxy networks with `Docker`, `Cloudflare Workers`, `Google Cloud`, `AWS`, and `Nginx`.
- **Automation & Integrations:** Developing third-party logistics/payment gateway integrations, P2P web tools, and automated workflow pipelines.
